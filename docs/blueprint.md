# **App Name**: PrecisionWrite

## Core Features:

- Text Analysis: Analyze user-entered text for grammatical, spelling, and punctuation errors.
- Error Correction: Automatically correct errors found in the text.
- Corrected Text Display: Display the corrected version of the text to the user.
- Detailed Feedback Report: Generate a comprehensive report detailing the percentage of errors, highlighting areas for improvement, and providing specific suggestions as a helpful tool.
- Interactive Chatbox: Provide an interactive chatbox for users to enter and receive text.

## Style Guidelines:

- Primary color: HSL(210, 60%, 50%) - A calming blue (#478CFF) to inspire confidence in the app's accuracy. Based on the concepts of knowledge and precision, a dark-mode color scheme is more appropriate for PrecisionWrite.
- Background color: HSL(210, 20%, 15%) - A dark, muted blue (#243042) to reduce eye strain and create a professional feel.
- Accent color: HSL(180, 50%, 50%) - A vibrant cyan (#4DD0E1) to highlight suggestions and important feedback.
- Body text: 'PT Sans', a humanist sans-serif for readability and a touch of warmth. Headline font: 'Space Grotesk' for a modern and scientific feel.
- Use clear, simple icons to represent different types of errors (grammar, spelling, punctuation).
- Design a clean and intuitive chat interface, with a clear distinction between user input and corrected output.
- Use subtle animations to highlight corrected text and provide visual feedback.

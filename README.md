# Procrastination Task Manager

A gamified task management web application designed to help users
organize their tasks, meet deadlines, and stay motivated.

## 🚀 Live Demo

[Open the application](YOUR_VERCEL_LINK)

## ✨ Features

- Create and manage tasks
- Set task deadlines
- Assign difficulty levels
- Earn points for completing tasks
- Track completed tasks
- Organized task dashboard
- Gamified productivity experience

## 🛠️ Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Firebase
